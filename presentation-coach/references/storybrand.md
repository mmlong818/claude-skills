# StoryBrand 框架参考

**来源**: Donald Miller · *Building a StoryBrand* (2017)
**适用**: 产品发布、销售演讲、创业Pitch、品牌故事、任何需要让听众产生"这是为我设计的"感觉的场合

---

## 核心哲学

每个伟大的故事都遵循同一结构，人类大脑已经被数千年的故事训练得对这个结构高度敏感。
**你的演讲不是你的故事，而是听众的故事。**

当听众感觉自己是主角，他们的大脑就会自动参与进来，寻找"故事会怎样发展"。

---

## 七元素框架

```
一个主角（听众）
  遇到了一个问题
    遇见了一位导师（你）
      给了他们一个计划
        号召他们行动
          从而避免失败
            最终获得成功
```

---

## 七元素详解

### 1. 主角 — 听众，不是你

主角是听众。他们有一个**渴望**（Desire）— 一件他们想要实现但还没实现的事。

- 找到听众最深层的一个渴望（不是三个，是一个）
- 这个渴望必须在你开场30秒内被明确说出来
- 示例: "每个创业者都想要一件事——让更多人知道他们正在解决的问题。"

### 2. 问题 — 三层递进

好的叙事揭示三层问题：

| 层级 | 类型 | 示例 |
|---|---|---|
| 外部问题 | 可观察到的实际困难 | "你的演讲PPT花了3小时，但听众5分钟就忘了" |
| 内部问题 | 由外部问题引发的挫败感 | "你开始怀疑自己是否真的能说服别人" |
| 哲学问题 | 更深层的对与错 | "花了心血的工作不应该就这样被忽视" |

**最有力的演讲同时触动这三层。** 大多数演讲只停留在外部问题。

### 3. 导师 — 你，但要克制

听众不需要另一个英雄，他们需要一个知道出路的向导。

导师出现时需要建立两件事：
- **共情 (Empathy)**: "我理解你正在经历什么"（不要跳过这步）
- **权威 (Authority)**: 为什么你值得被相信（数据、案例、经历）

**常见错误**: 太快展示权威，没有先建立共情。听众会感觉"你在炫耀，而不是帮助我"。

### 4. 计划 — 简单到3步

给听众一个清晰的行动路径，消除他们对"该怎么做"的焦虑。

计划必须:
- 不超过3个步骤（人类大脑对3最友好）
- 每步都有清晰的开始和结束
- 让听众感到"我能做到"

格式: 
```
第一步: [简单可执行的动作]
第二步: [具体的转变]
第三步: [达到的状态]
```

### 5. 行动号召 — 直接、具体、一个

- **直接型号召 (Direct CTA)**: 现在就要他们做的事（"立即注册" / "今天开始" / "投票支持"）
- **过渡型号召 (Transitional CTA)**: 降低门槛的第一步（"下载免费指南" / "预约15分钟通话"）

**一个演讲只能有一个主要号召**。多个号召等于零个号召。

### 6. 避免失败 — 展示不行动的代价

不采取行动的代价是什么？

- 不要夸大恐吓，但必须真实地让听众感受到损失
- 人类对损失的敏感度是对收益的2倍（损失厌恶）
- 用具体数字或场景描述，不用抽象警告

示例: "每个月继续用现在的方式，你将多花40小时在不产生价值的工作上。那是5个工作日。"

### 7. 成功图景 — 描述美好结局

采取行动之后，生活会是什么样？

- 描述得越具体越好（不是"更好的生活"，而是具体的画面）
- 这个图景应该是听众真正渴望的，不是你认为好的
- 用感官语言（他们会看到什么、感受到什么、别人会如何看待他们）

## Pitch专项：一分钟版本

当你只有60秒时，用这个框架：

```
"我注意到很多[目标听众]在[外部问题]上挣扎，
这让他们感到[内部感受]。
[你的方案/产品]提供了[一个简单计划]，
让你可以[具体行动]，
最终[成功图景]。"
```

---

## 输出格式

交付以下内容：
1. **主角渴望** — 一句话定义听众最深层的渴望
2. **三层问题** — 外部/内部/哲学，每层一句话
3. **导师出场** — 共情语言 + 权威建立（各2-3句）
4. **三步计划** — 清晰、可执行的行动路径
5. **行动号召** — 一个直接CTA + 一个过渡CTA
6. **失败场景** — 不行动的具体代价（用数字或场景）
7. **成功图景** — 采取行动后的具体生活画面
8. **60秒Pitch版本** — 完整逐字稿

# Winston 框架参考

**来源**: Patrick Winston · MIT "How to Speak" (40年讲授)
**适用**: 学术讲座、论文答辩、通用演讲、职业演讲

---

## 核心哲学

演讲的成功取决于：你的表达能力 > 你的写作能力 > 你的想法质量。
听众的注意力是有限资源，你的每一分钟都在竞争这个资源。

---

## 执行步骤

### 模块 A — 开场设计

**目标**: 前60秒赢得接下来的每一分钟。

1. **写出赋能承诺 (Empowerment Promise)**
   - 格式: "听完这场演讲，你将能够 ___"
   - 必须具体、可操作 — 不是"了解X"，而是"能做到Y"
   - 示例: ❌ "你将了解机器学习" → ✅ "你将能够判断哪类问题适合用机器学习解决"

2. **设计前60秒脚本**
   - 第1句: 赋能承诺
   - 第2-3句: 背景/为什么这个问题重要
   - 第4句: 为什么是现在（时机）
   
3. **删除清单** — 以下内容必须从开场删除：
   - ❌ 开场笑话（听众还没准备好）
   - ❌ "感谢邀请我来到这里"
   - ❌ 道歉（"我准备时间不多"）
   - ❌ 议程幻灯片（先给承诺，再给地图）

---

### 模块 B — 五星记忆框架 (Winston Star)

让核心观点在听众脑中留存数周。

| 元素 | 定义 | 要求 |
|---|---|---|
| **符号 Symbol** | 代表你核心观点的视觉物体 | 必须具体可视，不能抽象 |
| **口号 Slogan** | 一句话概括，可在会议中重复 | 无需解释即可传播 |
| **惊喜 Surprise** | 挑战听众既有假设的反直觉真相 | 必须真正令人意外 |
| **核心 Salient** | 整场演讲最重要的一个观点 | 只能一个，永远只有一个 |
| **故事 Story** | 展示观点如何在真实情境中发挥作用 | 足够具体又能引发共鸣 |

---

### 模块 C — 幻灯片审查 (10大罪行)

| 罪行 | 判断标准 | 修正方法 |
|---|---|---|
| 幻灯片太多 | 超过1张/分钟 | 合并或删除 |
| 每页字太多 | 超过20字 | 提炼成关键词 |
| 字体太小 | 小于40pt | 强制最小40pt |
| 照本宣科 | 念幻灯片上的字 | 幻灯片是视觉，话语是内容 |
| 使用激光笔 | 任何激光笔使用 | 用手势指向，站在屏幕旁 |
| 远离屏幕 | 站在投影仪前 | 站在屏幕侧边 |
| 无留白 | 内容塞满整张幻灯片 | 最多60%覆盖率 |
| 背景杂乱 | 公司logo+颜色主题 | 纯白背景，去掉logo |
| 合作者名单结尾 | 最后一页列名单 | 改为贡献页 |
| "谢谢"/"提问"结尾 | 最后一页是这两种 | 改为贡献页 |

---

### 模块 D — 贡献收尾

**最后一页必须是贡献页**，且在整个Q&A期间保持展示。

贡献页格式:
```
今天我展示了：
• [具体贡献1] — 一句话描述
• [具体贡献2] — 一句话描述  
• [具体贡献3] — 一句话描述
```

**结尾话语** — 用向听众致敬代替"谢谢"：
- "你们给了我这个机会，我希望这些想法对你们有用。"
- "这个领域因为有你们这样的人在做这件事而变得更好。"

---

## 输出格式

交付以下内容：
1. **赋能承诺** — 一句话
2. **前60秒脚本** — 完整逐字稿
3. **删除清单** — 列出需要删除的内容
4. **五星摘要** — Symbol / Slogan / Surprise / Salient / Story
5. **贡献页** — 可直接使用的版本
6. **结尾话语** — 完整逐字稿

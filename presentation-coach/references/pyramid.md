# 金字塔原理参考

**来源**: Barbara Minto · McKinsey & Company
**适用**: 董事会汇报、高管简报、咨询提案、任何决策场合

---

## 核心哲学

决策者时间极度有限。他们需要的不是你的思考过程，而是你的结论。
**先说答案，再给理由。** 这与学术写法完全相反——但在商业场合，它是最有效的。

---

## 金字塔结构

```
          ┌─────────────────┐
          │   核心结论/建议   │  ← 第一句话就说这个
          └────────┬────────┘
         ┌─────────┼─────────┐
    ┌────┴───┐ ┌───┴────┐ ┌──┴─────┐
    │ 论点1  │ │ 论点2  │ │ 论点3  │  ← 3-5个支撑理由
    └────┬───┘ └───┬────┘ └──┬─────┘
    数据/证据   数据/证据   数据/证据    ← 每个论点下的证据
```

**三个层级**:
- **顶层**: 你的核心结论或建议（"我们应该做X"）
- **中层**: 3-5个支撑论点（"因为A、B、C"）
- **底层**: 每个论点下的数据、案例、分析

---

## 执行步骤

### 第一步 — 定义核心结论

问自己："如果听众只能记住一句话，那句话是什么？"

格式选项:
- 建议型: "我们建议 ___ ，因为它将带来 ___"
- 判断型: "根据分析，___ 是目前最优选择"
- 警示型: "我们面临 ___ 风险，必须在 ___ 之前采取行动"

**检验**: 一个好的核心结论应该让听众立刻产生疑问（"为什么？"）——这就是你接下来要回答的。

---

### 第二步 — 构建支撑论点

每个支撑论点必须:
- **独立成立** — 即使其他论点不存在，这个论点本身也有价值
- **共同完整** — 所有论点合在一起，完整支撑核心结论
- **互不重叠** — 避免同一意思说两遍（MECE原则）

常见3论点结构:
| 类型 | 示例 |
|---|---|
| 问题-原因-解决 | 现状问题 / 根本原因 / 解决方案 |
| 利益-风险-时机 | 潜在收益 / 不做的代价 / 为何现在 |
| 数据-趋势-影响 | 当前数据 / 变化趋势 / 对我们的影响 |

---

### 第三步 — SCQA 引入（可选但强烈推荐）

在正式进入金字塔之前，用30秒建立情境共识：

- **S (Situation)**: 听众已知的背景事实（建立共识）
- **C (Complication)**: 打破平衡的变化或问题
- **Q (Question)**: 由此引发的核心问题（"那我们该怎么办？"）
- **A (Answer)**: 你的核心结论（金字塔顶端）

---

### 第四步 — 执行摘要幻灯片

第一张内容幻灯片 = 完整的金字塔摘要（Executive Summary）：
```
标题: [核心结论，一句话]

• 论点1: [一句话 + 关键数字]
• 论点2: [一句话 + 关键数字]  
• 论点3: [一句话 + 关键数字]

建议行动: [具体的下一步]
```

---

### 第五步 — 幻灯片标题规则

每张幻灯片的标题必须是**观点句**，而非**话题词**：
- ❌ "市场分析" → ✅ "中国市场增速放缓至3%，低于全球平均水平"
- ❌ "财务数据" → ✅ "Q3利润下降12%，主要由原材料成本上涨驱动"
- ❌ "竞争对手" → ✅ "前三大竞争对手均在加速数字化，我们已落后18个月"

---

## 输出格式

交付以下内容：
1. **核心结论** — 一句话，直接可用
2. **金字塔结构图** — 顶层 + 3个中层论点 + 各论点的证据指引
3. **SCQA引入** — 30秒开场情境建立
4. **执行摘要幻灯片** — 可直接放入PPT的内容
5. **幻灯片标题列表** — 将话题词改写为观点句
6. **Q&A预判** — 3个高管最可能追问的问题 + 建议回答思路
